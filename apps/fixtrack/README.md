# FixTrack

Shell app. Seluruh logic dan UI ada di `packages/core`; folder ini hanya
berisi identitas FixTrack: `lib/main.dart` (branding + daftar halaman),
`pubspec.yaml` (versi, warna splash/icon), `assets/`, `.env`, `android/`, dan
`ios/`.

Nama skrip melos untuk app ini: `fixtrack` (mis. `melos run fixtrack`). Jangan
`flutter run` langsung dari folder ini.

Dokumentasi, daftar perintah, applicationId / bundle id, dan cara rilis ada di
[`README.md` root](../../README.md).
